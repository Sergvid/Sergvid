## О подходе

В каждом проекте отдельно проработана защита от утечки данных: сэмплинг и
кодирование внутри пайплайна, отбор признаков внутри кросс-валидации,
хронологическое разбиение для временных данных, отдельная калибровочная
выборка.

Метрики выбираю под задачу, а не по привычке: accuracy бесполезна при
дисбалансе, PR-AUC и F1-macro информативнее, а для бизнес-решений считаю
approval rate, default rate и missed defaults rate.

Модели довожу до состояния, пригодного к внедрению: сохранённые артефакты,
проверка воспроизводимости предсказаний, функции инференса для сырых данных.
